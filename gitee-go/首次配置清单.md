## 第 1 步：注册 / 登录 + 实名认证

1. 打开 https://gitee.com ，注册或登录
2. 完成**实名认证**：右上角头像 → 设置 → 实名认证
   （不实名的话，在线编译这类服务会被限制）

---

## 第 2 步：添加 SSH 公钥

1. 复制上面那一整行公钥（从 `ssh-ed25519` 开始到 `StudyHub-TV` 结束）
2. 右上角头像 → **设置** → 左侧 **安全设置** → **SSH 公钥**
3. 点「**添加公钥**」，标题随便填（例如 `StudyHub-TV 自动上传`）
4. 把公钥粘贴进「公钥」框 → 点确定（可能要输登录密码验证）

> 加完后可以点公钥旁边的指纹，核对是否与上面的 `SHA256:H+ridG...` 一致。

---

## 第 3 步：创建一个空仓库

1. 打开 https://gitee.com/projects/new
2. **仓库名称**：`StudyHub-TV`
3. 选「私有」或「开源」都行
4. **不要勾选任何初始化选项**（不需要 .gitignore、Readme、许可证模板）
5. 点「**创建**」

---

## 第 4 步：选一种编译方式（编译必须靠这一步）

### 方式 A：一键构建（最简单，建议先试这个）

1. 进入仓库 → **管理** → 左侧 **基本信息** → **语言** 选 `Android` → 保存
2. 回到仓库首页，会出现「**下载 APK**」入口
3. 点 **新建构建** → 选 **Java 版本 17** → 构建类型填 `assembleDebug` → 开始构建
4. 等 3~8 分钟，构建完在页面上直接下载 APK

> ⚠️ **签名选项「保留签名配置」不要勾**。
> 不勾时 Gitee 会自动生成临时证书把 APK 签好，拷到电视上就能装。

### 方式 B：Gitee Go 流水线（配好后我推代码就自动编译）

1. 进入仓库 → 顶部「**流水线**」→ 点开通
   （**需要先绑定手机号**，免费；送 200 分钟 + 每月 500 分钟构建时长）
2. 点「**新建流水线**」→ 选「**空模板**」
3. 打开本项目文件 `gitee-go/build-apk.yml`，**把内容整段复制**，粘贴到在线编辑器里
4. **在流水线设置里把触发条件勾上「Push 事件自动触发」**（重要，这是自动编译的关键）
5. 点保存 → 再点「运行」先手动跑一次

## 常见问题

**Q：一定要两个方式都配吗？**
不用。建议先用**方式 A** 跑通一次（最快拿到能装的 APK），确认能编译之后再配方式 B 享受自动编译。

**Q：编译出现红叉怎么办？**
把日志里红色的那几行发我。第一次跑失败很正常，大概率是 Gitee 构建机的 Android SDK 版本或 Gradle 版本对不上，我来调。

**Q：为什么 APK 不能自动给你下载？**
Gitee Go 流水线**没有开放 API**，所以构建状态、日志、制品都只能从网页看，这个我没法代劳。

**Q：SSH 和令牌哪个好？**
SSH 更安全——你不用把任何密码或令牌交给任何人，私钥也一直留在这台电脑上。
代价是 SSH 不能调 Gitee 的 API，所以**建仓库这一步需要你在网页上点一下**。
